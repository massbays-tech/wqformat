# Convert state abbreviations to names

\`abb_to_state\` changes all state abbreviations in selected column to
state names.

## Usage

``` r
abb_to_state(.data, state_col)
```

## Arguments

- .data:

  Dataframe.

- state_col:

  String. Name of state column.

## Value

Updated dataframe where all state abbreviations in \`state_col\` have
been converted to names.
