# Convert state names to abbreviations

\`state_to_abb\` changes all state names in selected column to
abbreviations.

## Usage

``` r
state_to_abb(.data, state_col)
```

## Arguments

- .data:

  Dataframe.

- state_col:

  String. Name of state column.

## Value

Updated dataframe where all state names in \`state_col\` have been
converted to abbreviations.
